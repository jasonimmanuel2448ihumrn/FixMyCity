REST API Documentation for FixMyCity

Android app communicates with these endpoints over HTTP.

GET /api/reports

Query reports with filters: ?category=, ?status=, ?search=

POST /api/reports

Submit new report: { category, description, location, title, imageUrl, userId }

GET /api/reports/:id

Get full report details and timeline history

PATCH /api/reports/:id/status

Update report status: { status: 'IN_PROGRESS' | 'RESOLVED', note: '...' }

POST /api/auth/login

User login: { email, password }

POST /api/auth/signup

User registration: { name, email, phone, password }

GET /api/notifications

Get user notifications

GET /api/stats

Get system impact statistics

POST /api/upload

Upload image multipart form
